# API-Jrobot

## 📝 Descrição

O **API-Jrobot** é uma galeria de fotos do espaço, desenvolvida para exibir imagens de planetas, nebulosas, estrelas e galáxias. O projeto é construído com Django e oferece uma interface simples e intuitiva para navegar e visualizar imagens.

## ✨ Funcionalidades

- **Visualização de Imagens:** Navegue por uma coleção de fotos do espaço.
- **Busca por Tags:** Filtre imagens por categorias como "Planeta", "Nebulosa", "Estrela" e "Galáxia".
- **Interface Intuitiva:** Um layout limpo e fácil de usar para uma experiência de usuário agradável.

## 🚀 Tecnologias Utilizadas

- **Backend:**
  - Python 3.10
  - Django 4.1
- **Frontend:**
  - HTML5
  - CSS3
- **Dependências:**
  - `asgiref`
  - `python-dotenv`
  - `sqlparse`
  - `tzdata`

## ⚙️ Como Rodar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/exemplo-usuario/API-Jrobot.git
   cd API-Jrobot
   ```

2. **Crie e ative um ambiente virtual:**
   ```bash
   # Para Linux/macOS
   python3 -m venv venv
   source venv/bin/activate

   # Para Windows
   python -m venv venv
   .\venv\Scripts\activate
   ```

3. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   python manage.py runserver
   ```

5. **Acesse a aplicação em [http://127.0.0.1:8000/](http://127.0.0.1:8000/) no seu navegador.**
